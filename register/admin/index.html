Give someone a credit

Existing codes

A credit is a balance: spend $90 of a $792 credit and $702 stays on the code for next time. A percentage comes off one order and is then used up. Switching a code off stops it working immediately. Codes aren't locked to an email address, so only send one to the family it's for.

Referrals — 2 free tickets each side

A row appears when a brand-new family completes a paid registration through another family's share link. Both families are owed 2 tickets to any show — mark each side redeemed when the tickets are claimed at the box office.

Cash flow forecast

By month

Every scheduled payment

Every future auto-billing pull Stripe currently has on file — camp installments and class tuition. All pulls are charged on the 1st of the month. This is scheduled cash, not guaranteed: a failed card keeps appearing until Stripe's retries give up, and nothing here includes new registrations that haven't happened yet.
